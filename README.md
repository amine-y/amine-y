# Amine Yaakoubi

I keep e-commerce production from breaking: checkout, payments, releases and incidents.

Technical Team Lead at [Axelites](https://github.com/axelites) since 2022, developer there since 2018. I run the engineering behind a group of European home and furniture retailers: 6+ brands in 5+ countries on Magento / Mage-OS and Shopify, a Laravel ERP, and the payment flows between them.

**What I work on**
- **Production reliability:** releases, incident response, Black Friday peaks, security patching (PHP2Shell, Adobe backports)
- **Payments:** Revolut hosted checkout, Payline hosted page, HiPay, Stripe, Scalapay
- **AI in production:** a customer-facing support chatbot (Dify, now LangGraph), plus agent workflows for code review, QA and release prep
- **Team:** leading 6+ developers and interns, code review, CI/CD (Jenkins, SonarQube)

**Stack:** PHP · Magento 2 · Laravel · Vue · MySQL · PostgreSQL · Typesense · RabbitMQ · Docker · AWS · Jenkins · LangGraph

Most of my work lives in private client repos. What's public here is tooling, plugins and experiments.
